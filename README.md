# Sign Decoder
An app that recognizes text in photos of trail signs. 
Use the Vision and Translation frameworks to extract text from an image and translate it into another language.

Used machine learning to find text in an image. The built-in model was trained on a large number of images so that it can reliably recognize text within an image.
The `Vision` framework can do much more than find text in an image. It can also focus on a specific part of an image, track identified objects across multiple images, detect hand and body poses, and more. You also saw the power of machine learning with the Translation framework. While translation can be accomplished without machine learning, the Translation framework makes this process much simpler and more efficient.
